- (event) Session initialized for ttassistant architecture spine based on PRD prd-ttassistant-2026-09-21
- (decision) Working mode: Coaching path
- (decision) AD-1: Design Paradigm is Hexagonal (Ports & Adapters) with Orchestrated Application Flow. Binds: all modules. Prevents: I/O and terminal logic leaking into domain rules. Rule: ttassistant.domain must have zero dependencies on I/O or terminal libs; all external interactions pass through ttassistant.ports implemented by ttassistant.adapters; application services drive conversational workflows.
- (decision) AD-2: Two-Phase Repository Discovery & Pure-Python HCL Parser (resolves PRD §10 Open Question 1). Binds: Topology and HCL scanning. Prevents: NFR-2 scan latency breach and C-extension installation failures on enterprise Windows/Linux. Rule: Use streaming lexical indexing in Phase 1 to filter candidate files, followed by targeted pure-Python AST parsing (python-hcl2) in Phase 2 on candidates only. Zero compiled C binary extensions.
- (decision) AD-3: Scaffolding File Layout & Tier 2 Scope (resolves PRD §10 Open Question 2). Binds: Scaffolding and HCL emission. Prevents: Boilerplate bloat in long-tail resources and coupled dependency antipatterns. Rule: Generated module layout follows lean decoupled structure: main.tf (primary resource + security triad), data.tf (decoupled data sources only, zero remote state), and backend.tf (isolated Azure blob backend). Tier 2 omits variables.tf and outputs.tf by default; Tier 1 includes them for workload inputs/outputs.
- (decision) AD-4: Air-Gapped Deterministic Conversational Tweak Engine with Pluggable Port. Binds: Tweak handler and prompt refinement. Prevents: Credential/data leakage to external cloud services (NFR-5), API key dependencies, and high latency. Rule: Default tweak parser must be 100% local, deterministic AST modifier executing in <10ms with zero cloud API keys. TweakParserPort allows future enterprise LLM adapter without domain changes.
- (decision) AD-5: Governed Agency & Transactional Atomic Disk Mutation. Binds: Filesystem adapter and diff engine. Prevents: Silent file mutations, partial writes/corruptions on write failure (NFR-7), and terraform apply execution. Rule: Staged HCL lives purely in memory in StagedWorkspace. Greenfield diffs against empty state; remediation diffs against disk via difflib.unified_diff. Terminal requires explicit [Y] confirmation before disk writes. Writes must use .tmp files with os.fsync and atomic os.replace. Zero terraform apply.
- (decision) AD-6: Standards Engine Specification Schema & Fail-Fast Lifecycle. Binds: Standards engine and markdown parser. Prevents: Naming drifts, missing mandatory tags, and state backend collisions. Rule: CLI discovers and parses common_standards/*.md at startup using markdown-it-py into Pydantic models. Fails fast with exit code 1 if directory is missing. Naming schemas, mandatory tags, hub DNS zones, and blob backend configs are strictly enforced.
- (decision) AD-7: Automated Enterprise Security Triad Bundling for PaaS. Binds: Scaffolding engine and Tier 1 PaaS generators. Prevents: Naked PaaS resources, public exposure, and unlinked private DNS zones. Rule: Scaffolding any Tier 1 PaaS resource must: (1) set public_network_access_enabled = false, (2) scaffold azurerm_private_endpoint bound to discovered subnet, (3) scaffold private_dns_zone_group linked to central Hub Private DNS Zone. Upstream dependencies must be referenced strictly via data.azurerm_* in data.tf.
