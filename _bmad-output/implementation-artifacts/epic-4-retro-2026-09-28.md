Over 60 AzureRM attribute aliases map colloquial phrasing directly to schema attributes with type coercion, schema validation, and atomic snapshot rollback on error.
   - *Disposition*: `accept as-is`.

2. **Interactive Tweak Loop & Dynamic Diff Re-rendering (UX-DR4, FR-15, FR-16)**:
   - *Source*: `ttassistant/application/provisioning_flow.py`, `ttassistant/ports/terminal.py`, `ttassistant/adapters/terminal_adapter.py`.
   - *Observation*: The confirmation gate (`[commit]`, `[cancel]`, `[tweak]`) cleanly re-renders colorized unified diffs across multiple rounds of tweaking. The loop guarantees safe cancellation (exits cleanly without touching disk) and atomic commit only upon explicit human approval.
   - *Disposition*: `accept as-is`.

3. **Existing Folder Inspection & Non-Compliance Diagnostics (FR-14, AD-7)**:
   - *Source*: `ttassistant/domain/compliance.py`, `ttassistant/application/remediation_flow.py`, `tests/test_compliance_diagnostics.py`.
   - *Observation*: Non-destructive HCL AST parsing (`ReadOnlyHclAdapter`) audits existing monorepo directories against mandatory tags (`tagging_baseline.md`), naming conventions, and Enterprise Security Triad policies (`public_network_access_enabled = false` and companion `azurerm_private_endpoint` with Hub Private DNS zone group). Diagnostic tables render cleanly in both interactive Rich terminals and plain-text non-TTY / `TERM=dumb` environments. CI/CD gating mode (`--check`) terminates with exit code 1 when violations exist.
   - *Disposition*: `accept as-is`.

4. **Surgical HCL Patching & Comment Preservation (AD-5, NFR-5, NFR-7)**:
   - *Source*: `ttassistant/domain/patcher.py`, `ttassistant/application/remediation_flow.py`, `tests/test_remediation_staging.py`.
   - *Observation*: Non-destructive text-level patching completely avoids naive AST re-serialization (`hcl2.dump()` prohibited), preserving 100% of existing inline comments (`#`, `//`, `/* ... */`), block comments, single-line resource declarations, and custom indentation. Missing tags are injected or updated in-place preserving key quoting and trailing commas. Staged modifications live in-memory (`StagedWorkspace`) until the confirmation gate triggers atomic disk commit via sibling `.tmp` writes, `os.fsync`, and `os.replace`.
   - *Disposition*: `accept as-is`.
